## 📌 Project Overview

This project is a responsive URL Shortener homepage developed as part of the **Intern Front-end Developer Assignment** for **Bangla Puzzle Limited**.

The goal was to recreate the homepage design of [The Tiny](https://thetiny.site/) using modern front-end technologies, focusing on clean UI, responsive layouts, and reusable React components.

## ✨ Key Features

- 📱 Fully responsive layout for desktop, tablet, and mobile devices.
- 🎨 Clean and modern user interface.
- 🧩 Reusable React components.
- 🧭 Responsive navigation menu.
- 💜 Consistent colors, typography, and spacing.
- ⚡ Fast development and optimized build using Vite.
- 📐 Mobile-friendly layouts and flexible sections.




## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Ashiqweb123/Rabiul-Azim_Intern-Front-end-Developer.git
```

### 2. Navigate to the Project Folder

```bash
cd Rabiul-Azim_Intern-Front-end-Developer
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

### 5. Build for Production

```bash
npm run build
```
